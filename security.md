## 🛡️ Know Exactly How Secure You Are

**Strong Password Checker** is an advanced, client-side security utility designed to analyze the strength of your passwords against real-world attack vectors. 

Most websites just check for an uppercase letter and a number — that's not enough. This tool goes much deeper. It calculates the **entropy** of your password, checks it against massive databases of known leaked passwords (like HaveIBeenPwned), and simulates brute-force and dictionary attacks to estimate exactly how long it would take a hacker to crack it.

But it doesn't just tell you if your password is weak; it helps you fix it. The tool provides actionable recommendations, generates secure passphrases using the Diceware method, and visualizes the crack time in real-time as you type.

> 💡 **Why use this checker?** Because a data breach can ruin your life. Take control of your cybersecurity by ensuring every password you use is truly uncrackable.

## 🚀 Quick Start

> **Three steps. Under two minutes. No installation required.**

### 1️⃣ Access the app
Click the **Try Checker** button at the top of this README to open the web app in your browser.

### 2️⃣ Type your password
Enter a password into the input field. The strength meter and crack time will update instantly.

## ⚙️ How It Works

<div align="center">

| Layer | Responsibility | Tech |
|:---|:---|:---|
| 🖥️ **Frontend UI** | Dynamic updates and visual meter | `React` |
| 🧠 **Engine** | Calculates entropy and guesses | `TypeScript` |
| 🛡️ **Leak API** | Hashes password locally, checks prefix | `k-Anonymity (HIBP)` |
| 🎲 **Generator** | Uses crypto-safe random values | `Web Crypto API` |

</div>

The app uses the **k-Anonymity** model for checking leaks. It hashes your password locally using SHA-1, sends only the first 5 characters of the hash to the API, and checks the rest locally. This ensures your password is never exposed.

## ❓ Frequently Asked Questions

<details>
<summary><b>Is it safe to type my password here?</b></summary>

Yes! The entire app runs **100% in your browser**. Your password is never sent to our servers. The only external request made is a secure, anonymous prefix check for data breaches.
</details>

<details>
<summary><b>How accurate is the crack time?</b></summary>

It's an estimate based on an attacker using a high-end GPU (like an RTX 4090) capable of billions of guesses per second. If your time says "Centuries," you're very safe.
</details>

<details>
<summary><b>What is a passphrase?</b></summary>

A passphrase is a sequence of random words (e.g., `correct-horse-battery-staple`). It is much easier to remember than a random string of characters, but mathematically much harder to crack.
</details>

<details>
<summary><b>Can I self-host this?</b></summary>

Yes! The entire project is open-source. You can clone the repo, run `npm install && npm run build`, and host it on any static server.
</details>

<details>
<summary><b>How do I report a bug?</b></summary>

Open an issue on the GitHub repository. Include your browser version and a screenshot of the issue.
</details>
